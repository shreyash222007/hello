HTML Frames & <iframe> Embedding

Demonstrating embedding of Maps and External Pages using the <iframe> element

01 Embedding Google Maps
google.com/maps/embed — Nagpur, Maharashtra
Map Embed
HTML Code
<iframe
  src="https://www.google.com/maps/embed?pb=...Nagpur"
  width="100%"  height="400"
  allowfullscreen=""
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade"
  title="Google Maps — Nagpur">
</iframe>
02 Embedding OpenStreetMap
openstreetmap.org/export/embed.html — Nagpur
OSM Embed
HTML Code
<iframe
  src="https://www.openstreetmap.org/export/embed.html
       ?bbox=78.9,21.0,79.2,21.3&layer=mapnik&marker=21.146,79.088"
  width="100%"  height="380"
  loading="lazy"
  title="OpenStreetMap — Nagpur">
</iframe>
03 Embedding an External Webpage
en.wikipedia.org/wiki/World_Wide_Web
External Page
HTML Code
<iframe
  src="https://en.wikipedia.org/wiki/World_Wide_Web"
  width="100%"  height="480"
  loading="lazy"
  sandbox="allow-scripts allow-same-origin allow-popups"
  title="Wikipedia — World Wide Web">
</iframe>
04 Side-by-Side Layout (Modern Frameset Alternative)
Note: The old <frameset> and <frame> tags were removed in HTML5. Modern practice uses <iframe> inside CSS Grid to achieve the same split-pane layout.
Left — Google Map
Pane 1
Right — Wikipedia
Pane 2
HTML + CSS Code
/* CSS — replaces <frameset cols="50%,50%"> */
.split-layout {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 1rem;
}

<!-- HTML -->
<div class="split-layout">
  <iframe src="map-url"   height="280"></iframe>
  <iframe src="page-url"  height="280"></iframe>
</div>
05 iframe Attributes Reference
Attribute Description Example Value
srcURL of the page or resource to embed."https://example.com"
width / heightDimensions of the iframe in pixels or %."100%" / "400"
titleAccessible label for screen readers. Always include."Google Map"
loadingDefers loading until needed (performance)."lazy" | "eager"
sandboxRestricts embedded content for security."allow-scripts"
allowfullscreenLets the frame expand to full screen.(boolean)
referrerpolicyControls referrer header on requests."no-referrer-when-downgrade"
allowGrants browser features to embedded content."geolocation; fullscreen"
